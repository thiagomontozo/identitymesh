# Frontend

The web application uses React, TypeScript, Vite, React Router, Tailwind CSS and TanStack Query. The primary surfaces are the Identity Assurance Overview, People/Person 360, connectors, lifecycle cases, reviews, findings, evidence, reports and audit.

Status indicators pair text, icons/shapes and color. Forms use labels, keyboard-visible focus, semantic controls and accessible table structure. The UI never displays full connector credentials, session cookies, CSRF secrets or master keys. Authorization remains server-side.
